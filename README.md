# Maa NoGithub AutoUpdate

针对无法正常访问 GitHub 的用户，提供的 MAA 下载与更新工具集。

## 目录结构

```
Maa_全量下载最新版本(双击bat自动下载到当前文件夹内)/
├── Maa-Download-Latest.bat      # 入口：双击下载最新完整 zip 包
└── Maa-Download-Latest.ps1      # 从镜像源下载 MAA 最新版到当前目录

Maa_自动更新脚本(里面文件全部放入maa文件夹内)/
├── Maa-Update.ps1               # 核心更新引擎（版本检测、下载、安装、备份、回滚）
├── Maa-Debug-Update.bat         # 完整更新，执行完后暂停保留窗口，用于查看输出/反馈问题
├── Maa-静默更新版本.bat         # 只更新 MAA 版本，跳过游戏资源（静默模式）
└── Maa-静默版本资源全部更新.bat # 更新 MAA 版本 + 游戏资源（静默模式）
```

## 使用方法

### 全量下载

1. 进入 `Maa_全量下载最新版本(双击bat自动下载到当前文件夹内)/`
2. 双击 `Maa-Download-Latest.bat`
3. 下载完成后解压即可使用

### 自动更新（已安装 MAA）

1. 将 `Maa_自动更新脚本(里面文件全部放入maa文件夹内)/` 下所有文件复制到 MAA 安装目录（与 `MAA.exe` 同目录）
2. 根据需要选择运行：

   | 脚本                           | 说明                                                                   |
   | ------------------------------ | ---------------------------------------------------------------------- |
   | `Maa-Debug-Update.bat`         | 完整更新，窗口保留，适合首次运行/查看输出/反馈问题                     |
   | `Maa-静默更新版本.bat`         | 只更新 MAA 版本，跳过资源更新。资源更新失败时用这个，在 MAA 内更新资源 |
   | `Maa-静默版本资源全部更新.bat` | 版本 + 资源全更新，静默模式，用于自动化执行                            |

   游戏资源更新不稳定,建议在Maa内更新资源.

### 首次运行说明

- 第一次启动会比较慢，请耐心等待
- 脚本会自动检测并安装 PowerShell 7（用于 HTTP/2 下载）
- 如网络问题无法自动下载 pwsh，可手动安装后重试：
  1. 从微软商店安装：`https://apps.microsoft.com/detail/9mz1snwt0n5d`
  2. 或从 GitHub Releases 下载 `PowerShell-7.6.2-win-x64.msi` 放到 MAA 目录，脚本自动识别安装

### 日志与问题反馈

**推荐方法**：运行 `Maa-Debug-Update.bat`，右键标题栏 → 编辑 → 全选 → 复制，粘贴给开发者。

**保存到文件**：在 MAA 目录打开 cmd，执行：

```
powershell -NoProfile -ExecutionPolicy Bypass -File "Maa-Update.ps1" > update_log.txt 2>&1
```

生成的 `update_log.txt` 即为完整日志。

### 自动化运行

**配合 MAA 启动前脚本**：

1. 打开 MAA → 设置 → 运行设置
2. 将 `Maa-静默版本资源全部更新.bat` 拖入"开始前脚本"

**Windows 任务计划程序**：

1. 按 Win+R，输入 `taskschd.msc` 回车
2. 创建基本任务 → 名称填 "MAA 自动更新"
3. 触发器选每天/每周，操作选"启动程序"
4. 程序填 `powershell`，参数填：
   ```
   -NoProfile -ExecutionPolicy Bypass -File "C:\你的MAA路径\Maa-Update.ps1"
   ```
5. 如需只更新版本，参数末尾加 `-SkipResource`

## 运行要求

- 系统：Windows 10/11
- 网络：中国普通宽带/移动网络（已针对国内网络优化）
- 权限：管理员权限可自动安装 PowerShell 7（无管理员则用便携版）

## 更新逻辑

### 版本更新

- 优先使用 OTA 增量包（只下载差异文件，通常几 MB 到十几 MB）
- OTA 找不到则回退到完整安装包（几百 MB）

### 资源更新

- 使用 PowerShell 7 + HTTP/2 下载（国内网络必须）
- HTTP/2 失败则尝试多源镜像和多策略兜底

### 安装流程

1. 先下载更新包（MAA 仍在运行，不影响使用）
2. 下载完成 → 自动关闭 MAA → 备份旧文件 → 安装 → 重新启动 MAA

### 断点续传

- 使用 `.update_state` 文件记录状态，重新运行从断点继续
- 恢复失败时删除 `.update_state` 和 `.update_temp` 即可从头开始

## 主要特性

- **多镜像冗余**：自动从 `agent.imgg.dev`、`ghproxy.net`、`gh-proxy.com` 等多源降级下载
- **双 API 备份**：主备 API 自动切换，提高版本信息获取成功率
- **DNS 加速**：自动解析并加速 GitHub 相关域名
- **多下载引擎**：HTTP/2 → curl → 分片并发 → 单线程，自动降级
- **自动备份回滚**：备份在 `.update_backup` 文件夹，失败自动恢复
- **无需手动关闭 MAA**：更新前自动关闭，更新后自动重启

## 更新通道

所有脚本默认 `stable` 通道，如需修改，编辑 `.bat` 文件在 PowerShell 调用后添加对应参数：

| 参数             | 说明   |
| ---------------- | ------ |
| `-Channel beta`  | 测试版 |
| `-Channel alpha` | 开发版 |

## 常见问题

**Q: 双击 .bat 闪一下就消失？**
A: 用 `Maa-Debug-Update.bat` 查看错误信息。常见原因：文件没放到 MAA.exe 同目录、路径含空格、权限不足。

**Q: 提示 "PowerShell 下载失败" 但后续能更新？**
A: 版本更新走 curl 直连不需要 pwsh，只有资源更新才需要 pwsh HTTP/2。可从微软商店安装或手动下载安装包放到 MAA 目录。

**Q: 下载很慢/超时？**
A: 脚本内置多镜像多策略重试，一般会自动成功。如果总失败，检查网络、重置 hosts 或挂梯子。

**Q: 更新后 MAA 启动异常？**
A: 脚本自动保留备份在 `.update_backup`，手动覆盖回 MAA 目录即可回滚。

**Q: 什么是 OTA 增量更新？**
A: 只下载和旧版本有差异的文件，通常几 MB 到十几 MB，比完整包（几百 MB）快得多。
