# Maa NoGithub AutoUpdate

针对无法正常访问 GitHub 的用户，提供的 MAA 下载与更新工具集。

MAA（Maa Assistant Arknights，明日方舟游戏助手）是一个开源项目，最新版本放在 GitHub 上。
但 GitHub 在国内访问很慢甚至打不开，本项目就是为了解决"下不了、更新不了 MAA"的问题。

## 两种更新方式对比

|              | 全量下载覆盖                     | 增量更新（推荐）                |
| ------------ | -------------------------------- | ------------------------------- |
| **适合场景** | 第一次下载 MAA、MAA 损坏需要重装 | 已安装 MAA，日常版本更新        |
| **下载大小** | 完整包（约 250MB）               | 增量包（约 5~50MB），完整包兜底 |
| **下载速度** | 较慢（文件大）                   | 快（差异文件小）                |
| **保留配置** | 保留 config/、data/、resource/   | 自动备份恢复，不丢配置          |

### 全量下载覆盖

**优点**：

- 最简单，不需要任何前置操作
- 双击 bat 自动下载、自动覆盖安装
- 适合新手和完全不懂的用户
- 脚本会自动保留 config/data/resource 配置

**缺点**：

- 每次下载完整包（~250MB），比增量包大很多
- 网络差时下载时间较长
- 无法进行资源更新，建议配合增量更新脚本

### 增量更新（推荐）

**优点**：

- 下载量小（差异文件通常几 MB 到几十 MB）
- 支持只更新版本、不更新资源
- 可以配合 MAA 实现全自动更新（启动前脚本）
- 支持断点续传
- OTA 增量更新效率最高

**缺点**：

- OTA 找不到差异包时会回退到完整包

## 小白使用攻略

### 第一步：下载 MAA（从未安装过）

1. 下载本项目：百度网盘链接在最上方，或从 GitHub 下载
2. 解压后进入 `Maa_增量全量更新脚本\` 文件夹
3. 双击 `Maa-全量更新-静默.bat`（静默模式，无弹窗干扰）
4. 等待下载完成（约 250MB，根据网速 1~10 分钟）
5. 下载完成后脚本会自动覆盖安装到当前目录
6. 如果当前目录不是 MAA 目录，手动把下载的 zip 解压到 MAA 目录即可

### 第二步：日常更新（已安装 MAA）

1. 进入 `Maa_增量全量更新脚本\` 文件夹
2. 把里面所有文件**复制**到 MAA 安装目录（与 MAA.exe 同目录）
3. 双击 `Maa-增量-静默版本资源全部更新.bat`（版本+资源全更新）
4. 或者双击 `Maa-增量-静默只更新版本.bat`（只更新版本，跳过资源）
5. 如果想查看更新过程，双击 `Maa-增量-更新-Debug.bat`（保留窗口）

### 第三步：设置自动更新（可选）

1. 打开 MAA → 设置 → 运行设置
2. 将 `Maa-增量-静默版本资源全部更新.bat` 拖入"开始前脚本"
3. 之后每次启动 MAA 都会自动检查并更新

## 详细使用说明

### 方式一：全量下载覆盖

适合：第一次下载 MAA、MAA 损坏需要重装、完全不懂的新手

1. 进入 `Maa_增量全量更新脚本\`
2. 双击其中一个 bat：

   | 脚本                     | 说明                   |
   | ------------------------ | ---------------------- |
   | `Maa-全量更新-静默.bat`  | 静默下载覆盖，无弹窗   |
   | `Maa-全量更新-Debug.bat` | 保留窗口，便于查看输出 |

3. 脚本自动执行以下流程：
   - 获取最新版本信息（从 api.maa.plus）
   - 测试各镜像源速度，选择最快源
   - 下载完整安装包（约 250MB）
   - 检测当前目录是否为 MAA 安装目录
   - 如果是：备份 config/data/resource → 清理旧文件 → 解压覆盖 → 恢复配置
   - 如果不是：仅下载 zip，需手动解压
   - 删除已下载的安装包

### 方式二：增量更新

适合：已安装 MAA 的日常更新、希望自动更新的用户

#### 首次使用

1. 进入 `Maa_增量全量更新脚本\`
2. 把里面所有文件**复制**到 MAA 安装目录（与 MAA.exe 同目录）
3. 双击 `Maa-增量-更新-Debug.bat`（保留窗口，便于查看输出）
4. 脚本会自动：检测版本 → 下载增量/完整包 → 备份 → 安装 → 重启 MAA

#### 日常使用

| 脚本                                | 说明                                     |
| ----------------------------------- | ---------------------------------------- |
| `Maa-增量-静默版本资源全部更新.bat` | 版本+资源全更新（推荐）                  |
| `Maa-增量-静默只更新版本.bat`       | 只更新版本，跳过资源更新                 |
| `Maa-增量-更新-Debug.bat`           | 保留窗口，适合首次运行/查看输出/反馈问题 |

游戏资源更新不稳定，建议在 MAA 内更新资源。

#### 更新逻辑

- **版本更新**（三级回退）：优先 OTA 增量包（几 MB~几十 MB）→ OTA 失效则完整包 → 都失败时自动调用全量下载脚本覆盖安装
- **资源更新**：从 GitHub 镜像下载资源包，使用 jsdelivr CDN 兜底
- **安装流程**：先下载（MAA 仍在运行）→ 下载完成 → 自动关闭 MAA → 备份 → 安装 → 重启 MAA
- **断点续传**：使用 `.update_state` 文件记录状态，重新运行从断点继续
- **自动回滚**：备份在 `.update_backup` 文件夹，失败自动恢复
- **SHA256 校验**：下载后自动验证文件完整性，防文件损坏
- **代理流量优化**：增量包小走代理直连 GitHub 加速；完整包和资源包大走镜像省代理流量

## 首次运行说明

- 第一次启动会比较慢，请耐心等待
- 脚本会自动检测并安装 PowerShell 7（用于 HTTP/2 下载）
- 如网络问题无法自动下载 PowerShell 7，按以下顺序尝试：
  1. 从微软商店安装（国内可正常访问）：
     https://apps.microsoft.com/detail/9mz1snwt0n5d?hl=zh-CN&gl=CN
  2. 脚本会自动从微软 CDN 下载安装（dotnetcli.azureedge.net）
  3. 手动下载安装包放到 MAA 文件夹：
     a. 打开 https://github.com/PowerShell/PowerShell/releases
     b. 下载 PowerShell-7.6.2-win-x64.msi 或 .zip
     c. 放到 MAA 程序文件夹，脚本会自动识别安装

## 日志与问题反馈

推荐方法：运行 Debug 脚本，右键标题栏 → 编辑 → 全选 → 复制。

保存到文件：在 MAA 目录打开 cmd，执行：

```
powershell -NoProfile -ExecutionPolicy Bypass -File "Maa-Increment-Update.ps1" > update_log.txt 2>&1
```

生成的 `update_log.txt` 为完整日志，可发送给开发者分析。

## 运行要求

- 系统：Windows 10/11
- 网络：中国普通宽带/移动网络（已针对国内网络优化）
- 权限：管理员权限可自动安装 PowerShell 7（无管理员则用便携版）

## 主要特性

- **多镜像冗余**：自动从 `gh.ddlc.top`、`gh-proxy.com`、`agent.imgg.dev` 等多源降级下载
- **智能测速**：每次运行时自动测试各镜像源延迟，选择最快源下载
- **系统代理适配**：自动识别 HTTP_PROXY/HTTPS_PROXY 环境变量和 IE 代理设置
- **多下载引擎**：curl → HttpWebRequest → HTTP/2 → 分片，自动降级
- **增量/全量双保险**：增量更新失败时自动调用 `Maa-FullAmount-Download.ps1` 全量覆盖
- **自动备份回滚**：备份在 `.update_backup` 文件夹，失败自动恢复
- **无需手动关闭 MAA**：更新前自动关闭，更新后自动重启
- **不修改系统网络配置**：使用 curl --resolve 做进程级 DNS 加速，不改 hosts 文件

## 更新通道

所有脚本默认 `stable` 通道，如需修改，编辑 `.bat` 文件在 PowerShell 调用后添加对应参数：

| 参数             | 说明   |
| ---------------- | ------ |
| `-Channel beta`  | 测试版 |
| `-Channel alpha` | 开发版 |

## 常见问题

**Q: 双击 .bat 闪一下就消失？**
A: 用 Debug 版本查看错误信息。常见原因：文件没放到 MAA.exe 同目录、路径含空格、权限不足。

**Q: 提示 "PowerShell 下载失败" 但后续能更新？**
A: 版本更新走 curl 直连不需要 pwsh，只有资源更新才需要 pwsh HTTP/2。可从微软商店安装或手动下载安装包放到 MAA 目录。

**Q: 下载很慢/超时？**
A: 脚本内置多镜像多策略重试，自动选择最快源。如果总失败，检查代理设置或网络环境。

**Q: 更新后 MAA 启动异常？**
A: 脚本自动保留备份在 `.update_backup`，手动覆盖回 MAA 目录即可回滚。

**Q: 什么是 OTA 增量更新？**
A: 只下载和旧版本有差异的文件，通常几 MB 到几十 MB，比完整包（几百 MB）快得多。
