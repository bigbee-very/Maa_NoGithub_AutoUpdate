MaaEnd 下载与更新脚本 - 使用说明
================================

项目地址：
  https://github.com/bigbee-very/Maa_NoGithub_AutoUpdate

首次使用前请完整阅读本文档。


## 这是什么？

这是一个针对无法访问 GitHub 的国内用户，提供的 MaaEnd 下载与更新工具集。

适合的场景：
- 首次下载 MaaEnd
- MaaEnd 内置更新因网络问题失败
- MaaEnd 损坏需要重装


## 文件说明

| 文件 | 用途 | 说明 |
|------|------|------|
| `MaaEnd-FullUpdate-Download.ps1` | 全量下载引擎 | 从镜像获取最新完整包，自动覆盖安装 |
| `MaaEnd-全量更新-静默.bat` | 全量下载（静默） | 双击运行，无弹窗，推荐日常使用 |
| `MaaEnd-全量更新-Debug.bat` | 全量下载（调试） | 双击运行，保留窗口，便于查看输出/反馈问题 |
| `MaaEnd-全量更新-静默(beta).bat` | 全量下载·公测版（静默） | 更新到 beta/prerelease 版本 |
| `MaaEnd-全量更新-Debug(beta).bat` | 全量下载·公测版（调试） | 更新到 beta/prerelease 版本，保留窗口 |


## 使用方法

### 首次下载

1. 将本文件夹**复制到**你想放 MaaEnd 的位置（如 `D:\MaaEnd`）
2. 双击 `MaaEnd-全量更新-静默.bat`（或 `MaaEnd-全量更新-Debug.bat` 查看过程）
3. 等待下载完成（约 300MB，根据网速 1~10 分钟）
4. 脚本会自动检测当前目录：
   - 如果是 MaaEnd 安装目录（有 MaaEnd.exe）→ 自动覆盖安装
   - 如果不是 MaaEnd 安装目录 → 只下载 zip，需手动解压

### 已安装 MaaEnd 的更新

1. 将本文件夹内所有文件**复制**到 MaaEnd 安装目录（与 MaaEnd.exe 同目录）
2. 双击 `MaaEnd-全量更新-静默.bat` 即可
3. 脚本会自动完成：下载 → 备份配置 → 关闭 MaaEnd → 清理旧文件 → 解压覆盖 → 恢复配置 → 重启 MaaEnd

注意事项：
- config/、debug/ 目录会被自动保留，不会被覆盖
- 下载完成后自动删除安装包
- 如果下载失败，会自动尝试下一个线路（直连 / 代理 / 镜像）


## 更新通道

默认使用 stable（正式版）通道。双击 (beta) 后缀的 bat 即可更新到预发布版。

- `stable` — 正式版（默认）
- `beta`  — 预发布版（beta/rc 等先行版本）

说明：
- **beta 通道按版本号取最新**：会同时比较正式版与预发布版，取语义化版本更高者。
  如果预发布版已经落后于正式版（例如 beta 停在 2.32.0-beta.2，而 2.32.0 已正式发布），
  beta 脚本也会正确更新到 2.32.0，不会误报"已是最新"
- 版本号相同（如 `2.32.0` 与 `v2.32.0`）视为同一版本，不会重复下载
- 不会自动降级：本地版本高于可用版本时会提示并跳过


## 命令行参数

除了双击 bat，也可以直接调用 ps1 脚本（bat 都支持在末尾追加参数）：

| 参数 | 说明 |
|------|------|
| `-Channel beta` | 使用预发布版通道 |
| `-Force` | 强制重新下载安装（版本相同也执行） |
| `-DryRun` | 只探测版本与下载线路，不下载、不安装 |
| `-SelfTest` | 离线自测版本比较与选择逻辑，不联网不改文件 |
| `-Silent` | 静默模式（bat 已自动加上） |

示例：`MaaEnd-全量更新-静默.bat -Force`


## 更新逻辑

- **版本获取**：GitHub API 取版本列表（stable 按发布时间挑正式版，beta 按语义化版本取最高者）；
  API 不可达时自动从 `github.com` 发布页抓取 tag 列表降级
- **线路自动探测**：下载前实测「直连 GitHub / 代理 / 各镜像」哪条能通、哪条最快，按实测结果排序后再下载；
  直连或代理够快时自动跳过镜像探测
- **代理适配**：支持 `http://` 与 `socks5://` 代理（SOCKS5 由 curl 处理），代理探测失败不会影响直连
- **SHA256 校验**：GitHub 提供 `digest` 时校验下载文件；校验失败自动换源重试
- **自动安装**：先下载 → 关闭 MaaEnd → 备份 config/debug → 清理旧文件 → 解压覆盖 → 恢复配置 → 重启 MaaEnd


## 日志与问题反馈

推荐方法：运行 Debug 版本，右键标题栏 → 编辑 → 全选 → 复制，粘贴给开发者。

安装目录下的 `update.log` 为完整日志，可发送给开发者分析。


## 运行要求

- 系统：Windows 10/11
- 网络：中国普通宽带/移动网络（已针对国内网络优化）


## 常见问题

Q: 双击 .bat 闪一下就消失？
A: 改用 Debug 版本查看错误。常见原因：路径含空格、权限不足。

Q: 下载很慢/超时？
A: 脚本会实测各线路速度并自动选择最快源。如果总失败，检查代理设置或网络环境。

Q: 更新后 MaaEnd 启动异常？
A: 脚本自动保留备份在临时目录。运行调试版查看日志反馈给开发者。

Q: 下载完成后怎么用（全量方式）？
A: 如果脚本已自动覆盖安装，直接用 MaaEnd.exe 启动。如果只是下载了 zip，解压到你想放的位置即可。

Q: 明明有新版本却提示"已是最新"？
A: 现在版本比较是按语义化版本进行的。如果本地版本号高于所有可用版本（例如你在用预发布版而
   走的是 stable 通道），脚本会明确提示"本地 x 高于可用版本 y"并跳过，不会静默忽略。

Q: 想确认脚本会做什么，但不想下载 300MB？
A: 加 `-DryRun` 参数，只会打印目标版本、文件名和最快线路，然后退出。
