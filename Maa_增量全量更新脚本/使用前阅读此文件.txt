MAA 下载与更新脚本 - 使用说明
================================

项目地址：
  https://github.com/bigbee-very/Maa_NoGithub_AutoUpdate

首次使用前请完整阅读本文档。


## 这是什么？

这是一个针对无法访问 GitHub 的国内用户，提供的 MAA 下载与更新工具集。
包含两种使用方式：

- **全量下载覆盖**：一键下载最新版 MAA 完整包，适合第一次下载或重装
- **增量更新**（推荐）：优先下载差异文件（几 MB~几十 MB），日常更新用

## 全量下载覆盖（第一次下载 MAA）

适合：第一次下载 MAA、MAA 损坏需要重装

1. 把本文件夹**复制到**你想放 MAA 的位置或者已有的MAA文件夹（比如 `D:\MAA`）
2. 双击 `Maa-全量更新-静默.bat`（或 `Maa-全量更新-Debug.bat` 查看过程）
3. 等待下载完成（约 250MB，根据网速 1~10 分钟）
4. 脚本会自动检测当前目录：
   - 如果是 MAA 安装目录（有 MAA.exe）→ 自动覆盖安装
   - 如果不是 MAA 安装目录 → 只下载 zip，需手动解压

注意事项：
- 脚本会保留 config/、data/、resource/ 配置文件，不会被覆盖
- 下载完成后自动删除安装包
- 如果下载失败，会自动尝试下一个镜像源


## 增量更新（已安装 MAA 的日常更新）

### 首次使用

1. 将本文件夹内所有文件**复制**到 MAA 安装目录（与 MAA.exe 同目录）
2. 双击 `Maa-增量-更新-Debug.bat`（保留窗口，便于查看输出）
3. 第一次启动会慢，请耐心等待


### 日常使用

| 脚本 | 说明 |
|------|------|
| 脚本 | 说明 |
|------|------|
| `Maa-增量-静默版本资源全部更新.bat` | 版本+资源全更新（正式版，推荐日常使用） |
| `Maa-增量-静默只更新版本.bat` | 只更新版本，跳过资源更新（正式版） |
| `Maa-增量-更新-Debug.bat` | 保留窗口，适合查看输出/反馈问题（正式版） |
| `Maa-增量-静默版本资源全部更新(beta).bat` | 版本+资源全更新（公测版） |
| `Maa-增量-静默只更新版本(beta).bat` | 只更新版本，跳过资源更新（公测版） |
| `Maa-增量-更新-Debug(beta).bat` | 保留窗口调试（公测版） |

游戏资源更新不稳定，建议在 MAA 内更新资源。

### 更新逻辑

- **版本更新**（三级回退）：优先 OTA 增量包（几 MB~几十 MB）→ OTA 失效则完整包 → 都失败时自动调用全量下载脚本覆盖安装
- **资源更新**：从 GitHub 镜像下载资源包，使用 jsdelivr CDN 兜底
- **安装流程**：先下载（MAA 仍在运行）→ 下载完成 → 自动关闭 MAA → 备份 → 安装 → 重启 MAA
- **断点续传**：使用 `.update_state` 文件记录状态，重新运行从断点继续。恢复失败时删除 `.update_state` 和 `.update_temp` 即可从头开始
- **自动回滚**：备份在 `.update_backup` 文件夹，失败自动恢复
- **SHA256 校验**：下载后自动验证文件完整性，防文件损坏
- **代理流量优化**：增量包小走代理直连 GitHub 加速；完整包和资源包大走镜像省代理流量


## 设置自动更新（可选）

配合 MAA 启动前脚本：
1. 打开 MAA → 设置 → 运行设置
2. 将 `Maa-增量-静默版本资源全部更新.bat` 拖入"开始前脚本"
3. 之后每次启动 MAA 都会自动检查并更新

Windows 任务计划程序：
1. 按 Win+R，输入 taskschd.msc 回车
2. 创建基本任务 → 名称填 "MAA 自动更新"
3. 触发器选每天/每周，操作选"启动程序"
4. 程序填 powershell，参数填：
   -NoProfile -ExecutionPolicy Bypass -File "C:\你的MAA路径\Maa-Increment-Update.ps1"
5. 如需只更新版本，参数末尾加 -SkipResource


## 更新通道

默认使用 stable 通道。三种方式切换：

1. **使用独立 bat 文件**（推荐）：双击 `(beta)` 后缀的 bat 即可更新到公开测试版
2. **在现有 bat 后加参数**：`Maa-增量-静默版本资源全部更新.bat -Channel beta`

可用通道：
- `stable` — 正式版（默认）
- `beta`   — 公开测试版
- `alpha`  — 开发版

注意：从较旧版本首次切换到 beta 通道时，MAA 官方可能未提供
从该旧版本直达公测版的 OTA 增量包。此时脚本会自动回退下载
最新的正式版完整包。**第二次运行**时，即可从正式版匹配到
公测版的 OTA 增量包完成切换。此为正常行为，运行两次即可。


## 日志与问题反馈

推荐方法：运行 Debug 版本，右键标题栏 → 编辑 → 全选 → 复制，粘贴给开发者。

MAA安装目录文件夹下生成的 `update_log.txt` 为完整日志，可发送给开发者分析。


## 运行要求

- 系统：Windows 10/11
- 网络：中国普通宽带/移动网络（已针对国内网络优化）
- 权限：管理员权限可自动安装 PowerShell 7（无管理员则用便携版）


## 常见问题

Q: 双击 .bat 闪一下就消失？
A: 改用 Debug 版本查看错误。常见原因：文件没放到 MAA.exe 同目录、路径含空格、权限不足。

Q: 提示 "PowerShell 下载失败" 但后续能更新？
A: 版本更新走 curl 直连，不需要 pwsh。只有资源更新才需要 pwsh HTTP/2。可从微软商店安装或手动下载安装包放到 MAA 目录。

Q: 下载很慢/超时？
A: 脚本内置多镜像多策略重试，自动选择最快源。如果总失败，检查代理设置或网络环境。

Q: 更新后 MAA 启动异常？
A: 脚本自动保留备份在 .update_backup，手动覆盖回 MAA 目录即可回滚。

Q: 什么是 OTA 增量更新？
A: 只下载和旧版本有差异的文件，通常几 MB 到几十 MB，比完整包（几百 MB）快得多。

Q: 下载完成后怎么用（全量方式）？
A: 如果脚本已自动覆盖安装，直接用 MAA.exe 启动。
   如果只是下载了 zip，解压到你想放的位置即可。
