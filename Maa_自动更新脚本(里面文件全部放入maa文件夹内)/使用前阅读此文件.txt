MAA 自动更新脚本 - 使用说明
=============================

项目地址：
  https://github.com/bigbee-very/Maa_NoGithub_AutoUpdate

首次使用前请完整阅读本文档。


## 文件说明

将本文件夹内所有文件复制到 MAA 安装目录（与 MAA.exe 同目录）。

| 文件 | 说明 |
|------|------|
| `Maa-Update.ps1` | 核心更新引擎（版本检测、下载、安装、备份、回滚） |
| `Maa-Debug-Update.bat` | 完整更新，窗口保留，适合首次运行/查看输出/反馈问题 |
| `Maa-静默只更新版本.bat` | 只更新版本，跳过资源更新（静默模式） |
| `Maa-静默版本资源全部更新.bat` | 版本 + 资源全更新（静默模式） |


## 首次运行

1. 将本文件夹内所有文件**复制**到 MAA 安装目录（与 MAA.exe 同目录）
2. 双击 `Maa-Debug-Update.bat`（保留窗口，便于查看输出）
3. 第一次启动会慢，请耐心等待
4. 脚本会自动检测并安装 PowerShell 7（用于 HTTP/2 下载）

如网络问题无法自动下载 PowerShell 7，按以下顺序尝试：
1. 从微软商店安装（国内可正常访问）：
   https://apps.microsoft.com/detail/9mz1snwt0n5d?hl=zh-CN&gl=CN
2. 脚本会自动从微软 CDN 下载安装（dotnetcli.azureedge.net）
3. 手动下载安装包放到 MAA 文件夹：
   a. 打开 https://github.com/PowerShell/PowerShell/releases
   b. 下载 PowerShell-7.6.2-win-x64.msi 或 .zip
   c. 放到 MAA 程序文件夹，脚本会自动识别安装

游戏资源更新不稳定，建议在 MAA 内更新资源。


## 日志与问题反馈

推荐方法：运行 `Maa-Debug-Update.bat`，右键标题栏 → 编辑 → 全选 → 复制。

保存到文件：在 MAA 目录打开 cmd，执行：
  powershell -NoProfile -ExecutionPolicy Bypass -File "Maa-Update.ps1" > update_log.txt 2>&1

生成的 update_log.txt 为完整日志，可发送给开发者分析。


## 自动化运行

配合 MAA 启动前脚本：
1. 打开 MAA → 设置 → 运行设置
2. 将 `Maa-静默版本资源全部更新.bat` 拖入"开始前脚本"
3. 或者手动输入完整路径

Windows 任务计划程序：
1. 按 Win+R，输入 taskschd.msc 回车
2. 创建基本任务 → 名称填 "MAA 自动更新"
3. 触发器选每天/每周，操作选"启动程序"
4. 程序填 powershell，参数填：
   -NoProfile -ExecutionPolicy Bypass -File "C:\你的MAA路径\Maa-静默版本资源全部更新.bat"
5. 如需只更新版本，参数末尾加 -SkipResource
6. 注意：任务计划程序默认不显示窗口，先用 Maa-Debug-Update.bat 测试


## 运行要求

- 系统：Windows 10/11
- 网络：中国普通宽带/移动网络（已针对国内网络优化）
- 权限：管理员权限可自动安装 PowerShell 7（无管理员则用便携版）


## 更新逻辑

版本更新：优先使用 OTA 增量包（只下载差异，通常几 MB 到十几 MB），找不到则回退到完整安装包。

资源更新：使用 PowerShell 7 + HTTP/2 下载，失败后尝试多源镜像和多策略兜底（含 jsdelivr CDN）。

安装流程：先下载更新包（MAA 仍在运行）→ 下载完成 → 自动关闭 MAA → 备份旧文件 → 安装 → 重新启动 MAA

断点续传：使用 .update_state 文件记录状态，重新运行从断点继续。恢复失败时删除 .update_state 和 .update_temp 即可从头开始。

## 更新通道

默认使用 stable 通道。如需修改，编辑 .bat 文件在 PowerShell 调用后添加参数：
- `-Channel beta`  测试版
- `-Channel alpha` 开发版


## 主要特性

- 多镜像冗余：自动从 agent.imgg.dev、ghproxy.net、gh-proxy.com、jsdelivr CDN 等多源降级下载
- 双 API 备份：主备 API 自动切换
- 智能测速：自动测试各镜像源延迟，选择最快源下载
- 系统代理适配：自动识别 HTTP_PROXY/HTTPS_PROXY 环境变量和 IE 代理设置
- 多下载引擎：HTTP/2 → curl → 分片并发 → 单线程，自动降级
- 自动备份回滚：备份在 .update_backup 文件夹，失败自动恢复
- 无需手动关闭 MAA：更新前自动关闭，更新后自动重启
- 不修改系统网络配置：使用 curl --resolve 做进程级 DNS 加速，不改 hosts 文件


## 常见问题

Q: 双击 .bat 闪一下就消失？
A: 改用 Maa-Debug-Update.bat 查看错误。常见原因：文件没放到 MAA.exe 同目录、路径含空格、权限不足。

Q: 提示 "PowerShell 下载失败" 但后续能更新？
A: 版本更新走 curl 直连，不需要 pwsh。只有资源更新才需要 pwsh HTTP/2。可从微软商店安装或手动下载安装包放到 MAA 目录。

Q: 下载很慢/超时？
A: 脚本内置多镜像多策略重试，自动选择最快源。如果总失败，检查代理设置或网络环境。

Q: 更新后 MAA 启动异常？
A: 脚本自动保留备份在 .update_backup，手动覆盖回 MAA 目录即可回滚。

Q: 什么是 OTA 增量更新？
A: 只下载和旧版本有差异的文件，通常几 MB 到十几 MB，比完整包（几百 MB）快得多。
